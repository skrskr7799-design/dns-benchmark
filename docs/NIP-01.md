# NIP-01A — internal evidence contract and store (candidate)

Implements strict version-1 Observation, Measurement and Event records; immutable deterministic identity, explicit provenance, nullable measurements, typed units, bounded identifiers and no arbitrary raw payload fields. IDs for targets/profiles are SHA-256 of a canonical identity defined by the future producer adapter; not anonymization. Do not embed secrets in identifier fields. Source revision and part distinguish multiple observations per source record. Epoch seconds UTC; controller receipt timestamp assigned by store, remote observed timestamp is an agent claim, no skew policy until remote adapter. No fabricated timestamps or values. No public write endpoint or arbitrary producer input.

Derived SQLite store uses WAL, transactional batches with a durable monotonic per-stream cursor (one producer per stream, starts at 1), same-position exact replay, gap/stale/changed replay rejection, unique immutable identities, event-to-observation foreign keys, atomic event/evidence/cursor commit. Up to 100 records/256 KiB per batch, 256 streams, 200 records per keyset page, default 50k records/32 MiB logical JSON budget. Capacity rejects entire batch; explicit bounded retention deletes old events then unreferenced observations; surviving event references preserved. No silent pinned-evidence policy yet. Logical byte cap excludes indexes, WAL, cursor and filesystem overhead; physical disk quota/checkpoint/maintenance still required. Cursor persists across pruning; old source sequence rejected. A producer must never re-emit already-pruned source identities at new positions; no indefinite tombstones. Last-batch exact replay only. Source outbox/adapter and crash recovery across source databases not yet implemented; same-db atomicity is tested, not cross-db exactly-once.

This slice deliberately does not initialize the new database in app lifespan, schedule ingestion, expose APIs, add UI or backfill history. No runtime effect except backup allowlist extension. Existing DBs remain authoritative and unchanged. NIP-01B next: transactional benchmark source outbox with bounded drain and persisted source identity/cursor; prove crash before/after derived commit, deletion/retention semantics and saturation before enabling. Monitor/agent adapters follow with independent durable streams. Need coordinated scheduler and consumer contracts before NIP-02 scoring. CI includes contract/rollback/replay/concurrent ingestion/pagination/retention/schema and backup restore tests; new exact-head run pending.
