# Agent control mTLS — first integration candidate

Separate controller trust domain, optional deployment, TLS 1.3 directly over NetBird IPv4, no reverse proxy. One Uvicorn application and lifespan, second h11 listener in the same process. Internal port 8443 mapped to the exact NetBird host IP only by the opt-in Compose overlay. Main web port 8099 unchanged. Enable only after controller setup and NetBird ACLs restrict access. The listener accepts client-certificate-less TLS only for health and one-time CSR enrollment; all other machine requests require a verified client leaf, bound to the existing bearer credential in the database. No header-derived identity. Controller rejects all machine requests on the normal web port when enabled; bound credentials also fail on legacy transports after disabling. Legacy mode remains unchanged when not enabled. Schema 7 additive, backup includes private persistent control CA. Separate peer TLS remains unchanged.

Controller CA generated under data lock, protected 0600, persists through restarts. Server leaf created at startup, exact NetBird IP SAN, 365 days. Client generates P-256 key locally, signs CSR, controller verifies signature and ignores requested subject/extensions; 90-day client leaf, certificate fingerprint and expiry written atomically with token consumption. Existing rotate/revoke invalidates credential and pin. Enrollment response loss requires explicit rotation; no automatic renewal or CA rollover yet. Long-running server leaf renewal needs restart before expiry. CA private material included in private offline backups. Never copy CA private key or agent private key to another host.

Owner API GET /api/v1/agents/control-trust returns only origin, public CA PEM and SHA256 (owner session required). Bootstrap CA must come from a separately trusted channel and fingerprint checked; no trust-on-first-use, no disabling verification. Existing agent identities must be explicitly rotated and re-enrolled when switching origin/transport; do not reuse old spool. Configure agent NDC_AGENT_MTLS=1, NDC_AGENT_PROTOCOL=2, NDC_CONTROLLER_URL=https://NETBIRD_IP:8443, NDC_AGENT_CA_FILE=/data/controller-ca.pem. The current wizard still needs an explicit mTLS setup mode and migration flow. Do not deploy this branch in production yet: actual full-app TLS enrollment/HTTP bypass and restart tests, certificate expiry/renewal handling, UI download and physical VPS tests remain acceptance gates. CI test uses actual TLS and context propagation, plus transactional pin/rotation tests. No main merge.
