## NIP-05A1 — versioned compatibility and admission

Introduce explicit v2 machine contract and separate typed remote-probe task entry points; verify middleware machine authentication, body limits and rate limits before registering them. Persist task contract/version/kind independent of agent's latest heartbeat, migration defaults all old tasks to v1 DNS; no guessing kind from payload. ## NIP-05A2 — one bounded remote TCP/TLS/HTTP/route measurement
Use existing probe implementations, strict discriminated configurations (exact target host, port, family, kind, bounded route hops, HTTP HEAD only with no redirects/credentials or arbitrary headers). Local agent owner explicitly approves exact per-kind target and effective destination CIDRs; no wildcard scans or arbitrary command, URL callback, port range, or shell. Default deny new kinds without local config. Every resolved address must pass scope; pin connection to approved address; no redirect/rebinding bypass. Controller can only request registered probes. New local approvals separate from v1 allowed-endpoints.json; never auto-authorize on update. Execute via bounded worker with hard wall-clock deadline shorter than lease, cancellation/revocation kills worker; do not depend on a cooperative flag around blocking resolver. No extra host networking capabilities. Verify TLS normally, do not collect response bodies or private key material.

Versioned result schemas validate exact leased task, bounded fields/hops/finite metrics, protocol and family, outcome/stage consistency; agent-claimed time and controller received time distinct with clock skew/unknown indicators. Timeout/cancel/expiry is not a measured network failure. Failure stages separate DNS resolution, connect, trust and application response. Result replay hash and immutable identity include version and kind; preserve transactional evidence outbox, capacity and replay semantics. Never trust agent-provided scores or claim transport attestation. Tests for v1 compatibility, unsupported capability, cross-agent credentials, replay, cancellation, strict target and local scope, bounded results, migration and restore.
