## Score

Reliability = successful/attempted across matched complete series. Latency uses median of series p50, p95 and population jitter, not pooled percentiles. Latency component = 100/(1+metric/reference), references 20/50/10 ms respectively, versioned policy choices not external standards. Weighted score 0–100; component contributions visible. Balanced weights 60/15/20/5, reliability 80/5/10/5, speed 40/25/30/5. Score only if >=3 matched runs, >=30 attempts, >=20 successful queries and complete latency coverage for successful series. No score when evidence insufficient, not zero. Ties share rank. Recommendation only among >=2 scored targets, uniquely highest rounded score, observed success >=95%, no current benchmark backlog or stream error. Conditional on retained matched data, not a statistical confidence interval or uptime guarantee. No fallback independence claim, privacy/security/filtering score, auto-apply or automatic AdGuard writes. Users may select presets; custom weight editor later if justified.
